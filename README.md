# MauiAppEventos

Aplicativo desenvolvido em .NET MAUI para cadastro e resumo de eventos.

## Funcionalidades

- Cadastro do nome e local do evento.
- Definição das datas de início e término.
- Informação do número de participantes.
- Cálculo do custo por participante e do custo total.
- Exibição de um resumo com os dados cadastrados.

## Funcionalidade adicional

Além dos requisitos propostos para a atividade, foi adicionada a **diferença de tempo entre a data de início e a data de término do evento**, exibida em dias.

Essa funcionalidade foi incluída como um recurso extra, utilizando `DateTime` e `TimeSpan`, para complementar as informações apresentadas no resumo do evento.
